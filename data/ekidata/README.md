# 駅データ.jp の元データ

[駅データ.jp](https://ekidata.jp/) の無料データです。オーナーが会員登録してダウンロードしたものを、そのまま置いています。

| ファイル | 内容 |
|---|---|
| `company20260409.csv` | 事業者 |
| `line20260618free.csv` | 路線 |
| `station20260731free.csv` | 駅 |
| `join20260914.csv` | 隣り合う駅のつながり |

## 利用規約（2025年6月4日改定版）の要点

- 商用・非商用を問わず、連絡なしで利用できる（第4条）
- 加工して利用できる（第5条）
- 第三者へ提供できる。加工していないデータを提供する場合は無償にする（第6条）
- 出典の明記は不要だが、明記やリンクは歓迎されている（第4条）

公開リポジトリに無償で置くことは、第6条の範囲に入る。アプリでは、出典として駅データ.jpを表記する。

## 無料データで足りないもの

- 駅名の読み（`station_name_k`）が空になっている
- 路線カラーは一部の路線にしか入っていない（色はもともと自分で決める予定）

## アプリ用データへの変換

`npm run data:build` で `src/data/generated/rail.json` を作る（`scripts/build-rail-data.ts`）。変換のルールは次のとおり。

- 営業中（`e_status` が 0）の路線・駅だけを使う
- 都内に駅がある路線を取り出す。ただし、運転系統を表す路線（湘南新宿ライン、上野東京ラインなど）は除く（`scripts/rail/config.ts`）
- 路線を都県境で打ち切る。いったん都外に出て都内に戻る区間は、都外の駅を「通過するだけのマス」として残す（要件定義書 4.1、4.3）
- 打ち切ったあと、都内の駅が1駅以下になる路線は除く
- 同じ駅グループ（`station_g_cd`）の、別の路線の都内の駅を乗換でつなぐ
- 区市町村は住所から取り出す

## 更新するとき

1. 駅データ.jp から新しいファイルをダウンロードし、このフォルダのファイルを置き換える
2. `scripts/rail/files.ts` のファイル名を新しいものに変える
3. `npm run data:build` を実行し、テスト（`npm test`）が通ることを確かめる
